# DS Echo（安卓）

> 更新：2026-11-20（v0.4.16） ｜ 应用显示名 **DS Echo** ｜ 基于 DeepSeek 官方开源前端 chat-demo（MIT）＋ Capacitor 8 外壳

---

## 一、这是什么

一个装在自己安卓手机上的 DeepSeek 对话客户端。界面来自 **DeepSeek 官方 2026-11-12 开源的前端 `chat-demo`**，外面套一层安卓壳。

它和官方 App 的区别只有一处：**模型调用走您自己充值的 API Key，不占官方的免费额度**。所以官方那些限制（每日额度、7 天不活跃清会话、单次输入 4 万字）在它这里都不存在。

---

## 二、怎么装

1. 把 `DS-Echo-<版本>-debug.apk` 传到手机（微信文件传输助手/数据线/网盘都行）
2. 手机上点开安装，若提示「未知来源」，允许该来源安装
3. 桌面出现 **DS Echo** 图标（图标还是 Capacitor 默认素材，名字从 0.4.3 起已是 DS Echo）

**系统要求**：Android 7.0 及以上（安装包 `minSdkVersion` 24）。系统 WebView 需要 **Chrome 84 以上**才保证显示正常（老手机去应用商店更新「Android System WebView」）。Chrome 70–83 多数还能打开，但界面会错位。

如果内核还是太低，**不会白屏**——屏幕上会出现一页中文说明，告诉你当前内核版本、要求的最低版本、怎么更新，还有一个「打开自检」按钮可以逐项检查这台机器的能力。

## 三、第一次用

1. 打开 App，先看到一页 **使用前须知**（不是官方 App、费用自理、数据只在本机、模型可能出错），点「我知道了」
2. 接着自动弹出设置页，**输入 API Key**（在 https://platform.deepseek.com/api_keys 创建，以 `sk-` 开头）
3. 关闭设置，回到「有什么可以帮您？」的主界面
4. 底部有 **深度思考（DeepThink）** 和 **联网搜索（Search）** 两个开关，按需打开

须知只在第一次出现；想再看：设置 → 通用设置 → 使用前须知 → 查看。

填 Key 时产生的费用直接扣您 API 账户余额，App 本身不收费。

## 四、已经能做到的

- 流式回复、深度思考过程展开
- 联网搜索 + 来源引用、网页链接自动阅读
- 图片/PDF/Office 文件上传与识别（**图片支持 JPG / PNG / WebP / GIF**；其它格式在选择时就会被拦下并说明原因）
- 语音输入、回复朗读
- Markdown、代码高亮、数学公式、流程图渲染
- 多会话管理：自动起标题、重命名、删除、消息分支切换
- 深浅色主题、中英文切换
- **导入 DeepSeek 导出的历史对话 ZIP**（设置 → 数据管理 → 上传）。默认「合并导入」，不会清空现有对话；只有手动点「覆盖导入」才会先清空
- 导出全部对话为 ZIP（存到手机文件）
- **网络卡住会说人话**：连接 5 秒没响应、30 秒没开始回答、60 秒没有新内容，都会给出中文提示，不会一直转圈
- **手机横过来时用抽屉，不再被侧栏挡住内容**
- **会话可以分分组**：侧栏搜索框下面「新建分组」，会话的「⋯」里选「归到分组」；分组能折叠、重命名、删除（删除时会问「只删分组」还是「连会话一起删」）。搜索仍然跨分组
- **标题栏下面有一条状态栏**：左边显示 DeepSeek 账户余额（余额不足以调用 API 时变红），右边是上下文占用圆环与百分比；点圆环能看到「已用多少 / 上限多少」。没填 Key、请求失败或网络不通时显示 `--`，不会一直转圈
- **不带 `$` 的 LaTeX 也能渲染**：整段消息就是一个公式片段时按公式显示；普通句子里夹带的仍保持原文，代码块里的不动
- **公式里有不认识的命令时**：认识的部分照常显示，只把不认识的标红，不会整条消失
- **代码高亮支持 40 多种语言**：0.4.13 补了 Julia、Zig、Elixir、OCaml、Fortran、Verilog/VHDL、Solidity、Terraform、Nix、Lisp、Scheme、Clojure、Erlang、VB.NET、Groovy、Pascal、Less、GLSL、Regex

## 五、本地数据说明

- API Key 和设置存在 App 私有目录（别的 App 读不到）
- 对话内容存在手机本地数据库，**不上传到任何服务器**（除了发给 DeepSeek API 的部分）
- **卸载 App 会清空所有对话**，重要对话请先在设置里导出备份
- **余额与上下文上限会向 `api.deepseek.com` 查一次**：只把您的 API Key 作为凭证发过去，不经过任何第三方服务器。余额 60 秒内不重复请求，上限缓存 24 小时
- **升级到 0.4.16 后不要装回更早版本**：本地数据库升到了 12，旧版本打不开。往前升级、覆盖安装都不受影响

## 六、已知问题

| 问题 | 说明 |
|---|---|
| 启动画面是 Capacitor 默认图标（蓝色双箭头） | 还没换图，不影响使用 |
| 桌面图标是 Capacitor 默认图标 | 同上，换图标需要准备图片资源 |
| **状态栏底色跟随系统，不跟随 App 主题** | 系统浅色 + App 深色时，顶部会出现一条白色状态栏。原因：手机 WebView 内核低于 140 时无法真正全屏。已按兼容方式写好代码，内核 ≥140 的设备会自动正确 |
| **图片只支持 JPG / PNG / WebP / GIF** | 服务端只认这几种。BMP、TIFF、SVG、HEIC 等在选择时会被拦下，不会等到发送才失败 |
| **`.raw` 不能再作为附件** | 它同时是相机 RAW 和传感器数据格式，为避免误发而整体移除 |
| 语音输入未在真机验证 | 模拟器没有麦克风，权限已声明，需真机测 |
| 真实对话未验证 | 测试时用假 Key 只验到 401，真实对话需要您自己的 Key |
| 键盘弹出后的布局未验证 | 模拟器没有软键盘，需真机确认输入框不被挡 |
| **历史导入未在真机验证** | 导入口的在桌面浏览器里跑通过（构造的归档能合并成功、列表能刷出来），但「点上传后手机系统文件选择器是否弹出」只在桌面环境验证过。真机上如果点了没反应，设置页会给出提示，请把提示文字反馈回来 |
| **Chrome 70–83 的真实设备未验证** | 构建目标 70、支持承诺 84。本机只测过 Chrome 157，老内核上「能跑」与「错位到什么程度」都是推理结论，不是实测 |
| 没有应用内自动更新 | 想知道有没有新版，请到这里看：<https://github.com/KhalilYamber/DeepSeek-APP-Replica/releases> |
| **余额与上下文圆环的真机观感未验** | 本机用无头 Chrome 与探针验过；A58 等真机上状态栏高度与请求表现还没看 |
| **旧会话的圆环显示 `--`** | 0.4.12 及之前发的消息没有用量记录，发一条新消息后才有数字。这是预期，不是坏了 |
| **升级到 0.4.16 后不能降级** | 本地数据库版本升到 12，旧版本打不开；往前升级不受影响 |
| **分组功能真机未验** | 折叠手感、分组多了以后的滚动还没在手机上确认 |
| 这是 debug 包 | 体积略大；debug 包默认开放 WebView 调试口（方便开发），正式分发请打 release |

### 关于历史导入的两种方式

| | 合并导入（默认） | 覆盖导入 |
|---|---|---|
| 现有对话 | 保留 | 先全部清空 |
| 文件里已有的同名会话 | 跳过，不重复 | 整体替换 |
| 什么时候用 | 换手机、恢复备份、把几份导出合到一起 | 只想恢复成文件里的那份状态 |

导入结束会显示「已导入 N 个对话，跳过 M 个」。跳过通常是因为这份对话之前已经导入过；只有文件损坏的会话才会被单独跳过，不会让整包失败。

## 七、想自己改/重新构建

源码在 `../chat-demo/`（就是这个 APK 的全部代码）。

```
chat-demo/
├── src/              # 前端源码（React + TypeScript）
├── android/          # 安卓工程（Capacitor 生成）
├── dist/             # 构建产物（会被打进 APK）
└── capacitor.config.ts
```

重新构建（PowerShell）：

```powershell
cd chat-demo
pnpm build                        # 1. 构建网页（已换成跨平台脚本，Windows 可用）
pnpm exec cap sync android        # 2. 同步到安卓工程
cd android; .\gradlew.bat assembleDebug    # 3. 打 APK
```

需要先设好环境变量：`JAVA_HOME=<JDK 21 路径>`、`ANDROID_HOME=<Android SDK 路径>`。

产物：`chat-demo/android/app/build/outputs/apk/debug/app-debug.apk`

### 新增/改动的文件（相对官方源码）

| 文件 | 作用 |
|---|---|
| `src/services/native/platform.ts` | 判断是否在原生壳里；导出 ZIP 改走「写文件 + 系统分享」 |
| `src/app/useNativeShell.ts` | 接管安卓返回键、状态栏随主题变色 |
| `src/app/polyfills.ts` | 9 个运行时 API 垫片，让老内核不会因为缺少 `globalThis` 之类而崩 |
| `src/services/imageFormat.ts` | 读文件头判断图片真实格式（扩展名可以伪造） |
| `src/services/api/timeout.ts` | 三类超时与有限重试 |
| `src/check.html` | 兼容性自检页 |
| `src/index.html` | viewport 加 `viewport-fit=cover`；内联一段启动兜底脚本 |
| `rspack.config.ts` | 构建目标 `chrome >= 70`；loader 规则补 `.mjs` |
| `src/app/App.module.css` | 根容器加安全区 padding |
| `scripts/build.mjs` | 跨平台构建脚本（官方的是 Unix 语法） |
| `android/app/src/main/AndroidManifest.xml` | 加了麦克风权限 |
| `android/build.gradle` | Maven 换阿里云镜像 |
| `android/gradle.properties` | 允许中文路径构建 |

### 构建时的注意事项

- 构建依赖 JDK 21 与 Android SDK，路径按自己机器设置
- 构建前设 `JAVA_HOME`、`ANDROID_HOME`、`ANDROID_SDK_ROOT`
- 路径含中文，所以 `android/gradle.properties` 里有 `android.overridePathCheck=true`
- Maven 走阿里云镜像（`android/build.gradle` 里配好了）
- 官方 `package.json` 的 build 脚本是 Unix 语法 `rm -rf`，Windows 上不能直接用，要按上面的方式绕开
